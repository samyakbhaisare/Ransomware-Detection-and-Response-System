Runtime Settings

Enabled — durable SQLite history. Events, process snapshots, alerts, incidents and scores are written to persistence.db_path and survive an application restart.
Disabled — in-memory runtime data only. Everything works while RDRS is running, including stop/start of monitoring, but the history is lost when the application exits.
Switching to Disabled does not delete the existing database file, and switching back to Enabled makes the previously recorded history visible again.
